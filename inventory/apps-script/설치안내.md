# 자재 재고 앱 — 구글 연결 설치 안내

재고 화면(휴대폰·PC)은 깃허브 페이지에서 열리고, 자료는 내 구글 드라이브의 시트에 저장됩니다.
아래는 **처음 한 번만** 하면 됩니다. 10분쯤 걸립니다.

## 1. Apps Script 만들기
1. PC에서 https://script.google.com 에 들어가 **새 프로젝트**를 누릅니다.
2. 왼쪽 위 "제목 없는 프로젝트"를 눌러 이름을 `월드네트웍스 재고관리`로 바꿉니다.
3. 편집기에 있는 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣고 저장(Ctrl+S)합니다.

## 2. 권한 승인 (한 번)
1. 위쪽 함수 선택 칸에서 `firstRun`을 고르고 **실행**을 누릅니다.
2. "승인 필요" 창이 뜨면 내 구글 계정을 고르고 **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다.
   - 내가 직접 만든 스크립트라 구글이 검사하지 않았다는 뜻입니다.
3. 실행이 끝나면 내 드라이브에 `월드네트웍스 재고관리` 폴더가 생기고, 그 안에 시트와 `백업` 폴더가 만들어집니다.
   매일 새벽 3~4시 자동 백업도 이때 켜집니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 **웹 앱**을 고릅니다.
3. **다음 사용자로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 정하고 **배포**를 누릅니다.
   - "모든 사용자"여도 앱 비밀번호가 없으면 자료를 볼 수 없습니다.
4. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 앱에 연결
- 재고 앱을 열고 웹 앱 URL을 붙여 넣은 뒤, 처음 한 번 **앱 비밀번호**를 정합니다.
- 이 URL을 `inventory/index.html`의 `SCRIPT_URL_DEFAULT`에 넣어 두면 다른 기기에서는 주소 입력 없이 비밀번호만 넣으면 됩니다.

## 휴대폰 홈 화면에 앱으로 설치
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(크롬/삼성인터넷): 메뉴 → **홈 화면에 추가** 또는 **앱 설치**
- PC(크롬/엣지): 주소창 오른쪽의 **설치** 아이콘

## 코드를 고친 뒤
`Code.gs`를 바꿨으면 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. 이렇게 하면 웹 앱 URL은 그대로입니다.

## 직원별 재고 (2026-11 추가)
- 서버 코드가 바뀌었으므로 위 "코드를 고친 뒤" 방법대로 `Code.gs`를 통째로 붙여 넣고 **새 버전**으로 배포해야 합니다.
- 구글 시트에 `직원`, `직원재고` 탭이 처음 쓸 때 자동으로 생깁니다. 기존 `품목`, `입출고` 탭은 그대로입니다.
- 본사 출고 때 "받는 직원"을 고르면 그 직원 재고에 입고로 잡히고, 직원 재고에서 사용·반납하면 줄어듭니다. 반납은 본사 재고에 입고로 다시 들어갑니다.
- 직원용 비밀번호: 본사 화면 → 직원 관리 → "직원용 비밀번호"에서 정합니다. 이 비밀번호로 들어온 기기는 직원 화면(내 자재 입고·사용·반납, 내 이름 등록)만 보입니다.

## 사람별 로그인 · 권한 · 변경 기록 (2026-11 추가)
- 서버 코드가 바뀌었으므로 `Code.gs`를 통째로 붙여 넣고 **새 버전**으로 배포해야 합니다.
- 관리자 화면 → 직원 관리 → 사람 "수정" → **로그인 · 권한**에서 권한(직원/관리자)과 개인 비밀번호를 정해 알려 줍니다.
  - 로그인 화면에서 **이름 + 개인 비밀번호**로 들어옵니다. 이름은 앞부분만 넣어도 됩니다 (예: "이대진").
  - 직원 권한: 자기 자재만 보고 입고·사용·반납. 관리자 권한: 모든 기능.
  - 각자 "내 비밀번호" 버튼으로 비밀번호를 바꿀 수 있습니다.
- 예전 공용 비밀번호(본사·직원용)는 이름 칸을 비우고 넣으면 그대로 됩니다. 본사 공용 비밀번호는 잊었을 때를 위한 마스터 비밀번호로 남겨 둡니다. 모두 개인 비밀번호로 옮긴 뒤 직원용 공용 비밀번호는 직원 관리에서 끄면 됩니다.
- 구글 시트에 `변경기록` 탭이 생기고, 로그인·입출고·수정·삭제·취소가 누가·언제·어느 기기에서 했는지 한 줄씩 남습니다. 앱 위쪽 **변경 기록** 버튼으로 봅니다 (관리자만).
- `직원` 탭에 `권한` 칸(G열)이 자동으로 붙습니다. 개인 비밀번호는 시트가 아니라 스크립트 속성에 암호화(해시)해서 저장합니다.

## 재고 부족 알림 (2026-11 추가)
- 서버 코드가 바뀌었으므로 `Code.gs`를 통째로 붙여 넣고 **새 버전**으로 배포합니다.
- 메일을 보내는 권한이 새로 필요합니다. 편집기에서 함수 `authorizeMail`을 골라 **실행**하고, 뜨는 창에서 내 구글 계정 → 고급 → 이동 → **허용**을 누릅니다. (이걸 안 하면 앱이 서버에 연결되지 않습니다)
- 앱 위쪽 "재고 부족" 칸 또는 "알림 설정"에서 받을 이메일과 알림 방식(출고로 부족해지면 바로 / 매일 아침 8시 요약)을 고릅니다.
- 품목 수정에서 **적정재고**(발주할 때 채울 목표 수량)를 넣으면 발주 추천 수량이 그 기준으로 계산됩니다. 비우면 최소재고의 2배.
- 메일은 구글 계정 하루 한도(일반 계정 100통) 안에서 보냅니다.

## 현장별 자재 사용 집계 (2026-11 추가)
- 본사 출고(직원에게 주지 않을 때)와 직원 "사용" 기록에 **현장** 칸이 생겼습니다. 한 번 쓴 현장 이름은 다음부터 목록에 나옵니다.
- 앱 위쪽 **현장별 집계**에서 월별 또는 전체 기간으로 현장마다 어떤 자재를 얼마나 썼는지 보고, 엑셀·인쇄할 수 있습니다.
- 직원에게 준 출고는 직원이 사용할 때 현장이 잡혀서 두 번 세지 않습니다.
- 현장이 비어 있는 지난 기록은 내역 표의 **현장** 버튼으로 나중에 정할 수 있습니다.
- 시트 `입출고` J열, `직원재고` M열에 `현장` 칸이 붙습니다. 기존 칸은 그대로입니다.

## 거래처별 발주서 (2026-11 추가)
- 앱 위쪽 **발주** → "거래처" 탭에서 거래처를 추가하고, "우리 회사 정보"에 발주서 발신 정보를 넣습니다.
- 품목 수정에서 **주거래처**와 **단가**를 정해 두면, "새 발주서"에서 거래처를 고르고 **이 거래처 부족 품목 채우기**를 누를 때 부족 품목과 추천 수량이 자동으로 들어갑니다.
- 저장하면 발주번호(PO-날짜-번호)가 붙은 발주서가 나옵니다. **인쇄 / PDF**로 팩스·메일 첨부, **문자·카톡용 글 복사**로 메시지 전송.
- 물건이 오면 발주 목록에서 **입고 처리** → 받은 수량을 확인하면 본사 재고에 입고로 기록됩니다.
- 입고 기다리는 발주는 "재고 부족" 칸에 "발주 중"으로 표시돼 두 번 발주하지 않게 합니다.
- 시트에 `거래처`, `발주` 탭이 생기고, `품목` 탭 L·M열에 거래처ID·단가가 붙습니다.
